## 一、项目是什么

短剧场景 agent 能力底座，当前 workload = **分镜提示词 agent**：

- 输入剧本 → 每镜生成优化后的图像生成提示词（finalPrompt + rationale + reviewLog）
- 与旧系统提示词做**镜头级盲测对比**（服务端随机侧序、逐镜选优、双分打分）
- **成功标准：盲测对比赢过旧提示词**

团队：用户定架子 + 4 人分工（A 盲测页 / B prompt 调优 / C 模板部署 / D 测试报表）。

- `src/task-center/`、`src/tasks/`：任务中心适配层（mock）+ 任务 API
- `test/`：blind-score.spec.ts、shot-loop.spec.ts
- `scripts/e2e-blind.mjs`：14 断言 e2e
- 进度与决策详情：`agent-base/学习进度.md`（接续主文档）

## 四、主链路（最终版）

```
POST /tasks(剧本+配置) → 任务中心建档 → BullMQ 入队
→ LegacyImporter 调旧接口拿分镜列表+旧提示词（落 OldShot=盲测基线）
→ 每镜 Shot Loop（Director→Reviewer→Refiner，通过即停≤3轮熔断）
→ 落库 + 进度回写任务中心
→ 盲测打分页：GET pairs（随机侧序随任务缓存）→ 逐镜选优+双分 → POST scores（归因落 Score 表）
```
