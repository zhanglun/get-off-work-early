# embodied-data-loop

转型学习仓 + 具身智能数据闭环探讨。

## 目录结构

```
embodied-data-loop/
├── 转型路线图.md            # 总纲（你写的）：定位 / 领域概念 / 技术补强 / 作品策略
├── 转型4周计划.md           # 执行版总计划（你写的）：第 1-4 周做什么
├── exec/                    # 执行层：天级拆解 + 已搜好的学习资源
│   ├── 00-4周天级执行清单.md     # 已按你的节奏加速：第 1 周=全景+ROS（原1+2周）
│   ├── 01-具身智能全景.md
│   ├── 02-机器人软件栈与ROS.md
│   ├── 03-数据采集与数据集.md      # 新第 2 周（最重要，动手）
│   └── 04-平台工具与映射表.md      # 新第 3 周；新第 4 周=作品 demo 开工
└── outputs/                 # 产出层：你的作业（费曼笔记 / 图 / 映射表 / JD 收集）
    ├── 周1-笔记-具身智能是什么.md
    ├── 周1-图-数据闭环.md
    ├── 周2-图-传感器到执行.md
    ├── 周4-映射表-九州到机器人平台.md
    └── JD收集.md
```

## 用法

1. 每天看 `exec/00-4周天级执行清单.md` 对应的一天，做该做的事；
2. 资源文件（`exec/01~04`）里是已搜好/整理好的链接和速览，直接点开，不用自己搜；
3. 产出物写进 `outputs/` 对应模板，**用你自己的话写**（费曼法：写不出来 = 没懂）；
4. 完成标准见天级清单和原计划——"能解释 / 能做出来"才算完成，不是"看完了"。

## 节奏

工作日 1-1.5h，周末 2-3h。每天推进 30 分钟，比每天焦虑 8 小时强。
