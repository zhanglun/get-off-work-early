# 资源：平台工具实战 + 映射表（新第 3 周）

用途：第 3 周 D1-D6（天级清单已重排）。三个工具各半天，目标不是精通，是**能诚实写进简历 + 知道它们解决什么问题**。

## D1：DVC（数据版本控制，半天）

- ⭐ [dvc.org 官方文档](https://dvc.org/doc/start) —— Quick Start：`dvc init` → `dvc add` → `dvc push`。
- 用第 2 周的数据（或造一个小目录）体验版本化：改数据→`dvc add`→`dvc checkout` 回滚。
- 一句话理解：**Git 管代码，DVC 管数据/模型文件**。机器学习场景的大文件版本管理。

## D2：Label Studio（标注平台，半天）

- ⭐ [labelstud.io 官方文档](https://labelstud.io/guide/) —— Quick Start：建项目 → 导入数据 → 标注几条。
- 重点体验：**任务分配、标注模板（图像/视频/文本）、导出格式（JSON/COCO）**——这就是你 demo 里"标注任务分配"模块的原型。
- 用第 2 周的图像帧做标注对象，标注"抓取目标物"之类，体验最真实。

## D3：MLflow（训练生命周期管理，半天）

- ⭐ [mlflow.org Quickstart](https://mlflow.org/docs/latest/getting-started/index.html) —— 跑通官方 quickstart。
- 必须搞懂三个概念：**Experiment（一次实验项目）/ Run（一次训练）/ Model（产物模型注册）**。
- 一句话理解：**记录"哪次训练、用什么数据、什么参数、效果如何"**——对应你九州"模型统一接入"的机器人版。

## D4-D6：映射表（本周末期核心作业）

- 模板：`../outputs/周4-映射表-九州到机器人平台.md`（参考行已给）。
- 填表方法：
  1. 先列出九州你亲手做过的事（任务中心/模型接入/AI 长任务调度/组件库/音视频处理…）；
  2. 每一项找机器人平台的对应物（参考行有示例）；
  3. 每条自问："这个映射面试时能讲出故事吗？"——讲不出就补细节或删掉；
  4. 填完挑 3 条最强的，改写成简历 bullet。
