# 资源：仿真 + 数据采集 + 数据集（新第 2 周，最重要）

用途：第 2 周 D1-D6（天级清单已重排）。这周的产出直接变成你作品 demo 的数据层。
> 注意：Open X-Embodiment 是 **1M+ 条轨迹、几十 GB 级**的数据集——不要全下，选一个小数据集或只下几个 episode。

## D1：仿真

- ⭐ [NVIDIA Isaac Sim 官方文档](https://docs.isaacsim.omniverse.nvidia.com/) —— 跟着 Getting Started 装。要求：RTX 显卡。没有 RTX 显卡的替代：用 [Isaac Lab 文档](https://isaac-sim.github.io/IsaacLab/) 了解概念 + [MuJoCo](https://mujoco.org/)（CPU 可跑、轻量、学概念足够）。
- 目标不是跑通，是**建立"仿真是数据来源"的心智模型**：仿真生成"合成数据"→ 但存在 sim-to-real 差距（第 1 周四大路线里"合成数据"的利弊）。

## D2：遥操作

- ⭐ [Mobile ALOHA 官网中文页（低成本全身遥操作数据采集）](https://mobile-aloha.github.io/cn.html) —— 斯坦福开源项目，讲"怎么用低成本设备录人手示范数据"，含视频和失败案例，D2 首选。
- [B站：开源低成本遥操作系统 ALOHA（斯坦福 2023）](https://www.bilibili.com/video/BV1h84y1T7yV/) —— 5 分钟看懂 ALOHA 长什么样、怎么操作。
- [UMI ver.2 开源：毫米级数据采集手持系统 — OSCHINA](https://my.oschina.net/u/9745999/blog/19718289) —— UMI = 手持式采集设备（不用真机也能录人手轨迹），代表"无本体采集"路线。
- 关键概念：**遥操作 = 人通过设备（手柄/动捕/示教臂/UMI 指套）远程操控机器人，录下"人怎么做"的轨迹**——这是真机高质量数据的主要来源（贵、慢）。
- ⭐ 腾讯 HyVLA 的指套式 UMI 案例（把人类示教变成训练数据）：[GitHub: Tencent-Hunyuan/Hy-Embodied-0.5-VLA](https://github.com/Tencent-Hunyuan/Hy-Embodied-0.5-VLA)（含 2K+ 小时 UMI 数据集）+ [数据集页面](https://huggingface.co/datasets/tencent/Hy-Embodied-0.5-VLA-Data)。它用动捕替代 SLAM、采集时同步力/力矩——看它怎么设计采集体系，对你设计"采集端"很有启发。

## D3-D5：Open X-Embodiment（核心作业）

- ⭐ [Open X-Embodiment 官网](https://robotics-transformer-x.github.io/) —— 1M+ 条真机轨迹、22 种机器人本体、60 个数据集、34 个实验室。这是你 demo 最该用的真实数据源。
- ⭐ [GitHub: google-deepmind/open_x_embodiment](https://github.com/google-deepmind/open_x_embodiment) —— 数据集清单（Google Sheet 里有每个子数据集名字/大小）、下载方式：
  - 方式 1（TFDS）：`pip install tensorflow_datasets` + `tfds.load('fractal20220817_data')`（数据集名字从 sheet 里挑小的）
  - 方式 2（gsutil 直下）：`gsutil -m cp -r gs://gdm-robotics-open-x-embodiment/{dataset_name} ~/tensorflow_datasets/`
  - 先看 [数据集清单 sheet](https://docs.google.com/spreadsheets/d/1rPBD77tk60AEIGZrGSODP9a1ZTHlIm3L8ZP1qUZJcWg/)，**挑一个标注 size 小的**（如 `fractal20220817_data` 或 `utokyo_xarm` 系列），避免 GB 级下载。
- 数据格式：**RLDS**（[rlds 文档](https://github.com/google-research/rlds)）——数据组织成 **episode（episode = 一条完整轨迹）**，每个 episode 是一系列 step，每个 step 有 observation（观测：图像/关节角/力）和 action（动作）字段。
- ⭐ 读不懂 TFDS 的替代方案：用 PyTorch 版 [TorchRL 的 OpenX 加载器](https://docs.pytorch.org/rl/stable/reference/generated/torchrl.data.datasets.OpenXExperienceReplay.html) 或社区项目 [Torch-X-Embodiment](https://github.com/Stardust-hyx/Torch-X-Embodiment)（tf-record → torch，适合你这种不熟 TF 的工程师）。
- D5 可视化：读出来后画**关节角度随时间曲线**或**末端位置轨迹**——这就是"一条轨迹长什么样"的第一印象。

## D6：写数据笔记的要点

1. 目录结构 / 格式（RLDS episode→step 层级）
2. observation 里有哪些字段（图像、关节角、力…）
3. 时间戳怎么对齐（多传感器频率不同怎么同步）
4. 一条轨迹的数据量估算（对你设计存储/上传/可视化平台的意义）
