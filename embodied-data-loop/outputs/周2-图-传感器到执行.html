传感器 → 执行：机器人实时控制与数据平台

左侧是不能被平台阻塞的毫秒级控制闭环；右侧是异步的数据/训练平面。平台通过旁路录制 ROS 话题，而不是串在控制关键路径中。

实时控制平面

  • • 延迟目标：毫秒级
  • • 路径：传感器 → 感知 → 规划 → 控制 → 执行
  • • 平台不能阻塞此链路

数据 / 训练平面

  • • 延迟范围：秒到天级
  • • 旁路录制 ROS 话题到 rosbag
  • • 接入、对齐、清洗、标注、版本化、训练

平台的边界

  • • 记录运行数据，不参与实时控制
  • • 管理数据集、训练任务、模型版本
  • • 仅将验证后的模型部署回机器人
