# DESIGN.md — 短剧分镜制作助手「场记日志」视觉世界

> 由 impeccable 流程建立：方向经用户两轮选择（safer 寄存器 → 场记日志），构图经用户选定（comp-c 编号边栏，1600×1000）。
> 适用于本项目所有界面：视觉稿与后续实现一律以此为基线。

## 世界（Own-World）

产品是一本场记的连续性日志：剧本登记进来，场/镜/条逐一编号入册，穿帮用红笔记录，圈码标出当前进行中的条目。

## 色彩（Restrained 策略：中性底 + 功能色各司其职）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f7f6f1` | 日志纸底（全局画布） |
| `--paper-2` | `#f1efe8` | 次级纸面（边栏、页头） |
| `--card` | `#ffffff` | 卡面（登记条目、图版） |
| `--ink` | `#22242c` | 墨黑：正文与 1.5px 结构线 |
| `--ink-2` | `#565a66` | 次级文字 |
| `--ink-3` | `#666b78` | 三级文字（纸上 ≈4.9:1，通过 AA） |
| `--rule` / `--rule-2` | `#d9dcd4` / `#e7e9e2` | 细分割线（日志行线） |
| `--blue` | `#1f5f8b` | 工作蓝：动作、链接、进度条（唯一行为色） |
| `--red` | `#c0392b` | 校对红：穿帮、失败、MOCK 印章 |
| `--gold` / `--gold-deep` | `#b8860b` / `#8a6508` | 圈码金：手圈数字、当前项与注意标记（文字用 deep 保证对比度） |

色彩纪律：蓝只出现在可操作处；红只出现在问题与印章；金只画在圈码数字、当前态与注意标记（措辞类穿帮等）；颜色永不做装饰。

## 字体

| 角色 | 字体 | 用途 |
|---|---|---|
| 界面正文 | `"Noto Sans SC", -apple-system, "PingFang SC", ...` | 全部 UI 文字；标题用 700 字重，不用衬线 |
| 编号/时间码 | `"SF Mono", ui-monospace, Menlo` | 仅限：场镜条编号、时间戳、版本号、计数（数字即数据，不是造型） |
| 眉批 | `"Kaiti SC", "STKaiti"` | 助手的旁注、提示语、共享说明（手写批注传统） |

禁：衬线显示字、等宽字作氛围造型、>0.08em 字距。

## 结构语法

- **分区用 1.5px 墨线**（顶栏底、列间、图版头），行分隔用 1px rule；阴影基本不用（唯一高度系统=边框；admin 弹层允许一处 0 4px 14px 的软投影）。
- 圆角一律 2px（矩形日志气质）；无 pill。
- **圈码（签名元素）**：SVG 手绘椭圆圈住数字——进行中的阶段/镜头用金色并带描线动画（`draw-circ` 1.1s，reduce-motion 关闭）；已完成条目用墨色细圈。
- **印章**：红色描边小印（MOCK 模式标识），-2° 微倾。
- **勘误原语**：修改 diff = 划掉（红）→ 替换（蓝底），源自校对传统。
- **红色页边线**：边栏右缘 1px `rgba(192,57,43,.25)`，日志本的物理记忆。

## 布局（工作区 = comp-c 构图）

```text
┌─ 顶栏 64px：返回 · 项目名 · 剧集选择 · [MOCK] · 导出 ZIP ─┐
│ 编号边栏 118px │ 对话列（弹性）        │ 图版列 44%        │
│ 场1-5 镜号区间 │ 登记/回复/进度卡      │ 分镜图版/资产/穿帮 │
│ + 资产/穿帮/包 │ 输入框（常驻底部）    │ （按需分节滚动）   │
└───────────────────────────────────────────┴───────────────────┘
```

- 桌面端（≥1200px）：固定 1600×1000 舞台按视口等比缩放（画板模式，`--stage-s`）。
- 窄屏（<1200px 隐藏边栏；<980px 三列改纵向堆叠）。
