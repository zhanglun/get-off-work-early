# 产品形态决策：对话即产品（Form v2）

> 日期：2026-08-30
> 来源：用户脑爆确认。三个答案：① 第一屏是对话输入框（"就像 Codex 和 DeepSeek"）；② 编辑方式直接打字；③ 最接近的产品是 Codex、DeepSeek。
> **地位：形态层最高决策，推翻此前所有"工作台/多页面"假设；PRD 产品原则层不变。**

## 1. 一句话形态

> 对话是唯一入口：第一屏是一个输入框；生成过程是对话里的活动流；产出物是对话里的内联工件；修改靠打字；导出是工件上的一个按钮。

对标心智：Codex（活动流 + 工件）× DeepSeek（首屏即对话框 + 会话历史）。

## 2. 三个界面状态

### 空态（第一屏）

居中品牌 + 一句邀请（"把一集剧本贴进来"）+ 大输入框（粘贴 / 拖入 .md·.txt）。左侧是会话历史栏。没有统计面板、没有页签导航。

### 运行态

用户消息（剧本，折叠显示字数）之后，agent 以**活动流**回应：阶段行（✓ 剧本解析 · 3.2s / ● 分镜生成 26/42 / ○ 连续性检查），可折叠、终态收敛。**工件随生成实时长出来**：故事资产组、场次组、分镜卡逐个出现。用户可以随时离开，回来接着看（会话恢复）。

### 沉淀态（生成完成后，同一会话内）

制作摘要工件（数量 + 问题数 + 用时）、问题工件（按 G1A 区分措辞/事实类）、分镜工件（按场次分组、可折叠）、生产包工件（9 文件 + 导出按钮）。对话继续：用户打字修改（"把林小雨的风衣改成深灰大衣"）→ agent 影响分析 → 重生成 → 新版本工件出现在对话里。

## 3. 工件系统

| 工件 | 内容 | 折叠规则 |
|---|---|---|
| 剧本消息 | 用户粘贴/上传的剧本 | 默认折叠，显示字数 |
| 活动流 | 阶段、工具活动、耗时 | 运行中展开当前项；完成后折叠为一行"生成完成 · 用时" |
| 资产组 | 角色/场景/道具卡 | 默认收起为一行摘要，展开看卡片 |
| 场次/分镜组 | 按场次分组的分镜卡 | 默认展开当前讨论的场次，其余折叠 |
| 问题汇总 | 按 G1A 分措辞类/事实类 | 默认展开；措辞类带"自动修订"，事实类只有定位/忽略 |
| 制作摘要 | 数量统计 + 用时 + 模式 | 完成时出现一次 |
| 生产包 | 9 文件清单 + manifest 预览 + 导出按钮 | 默认折叠为一行 |

## 4. 交互原则

- **打字优先**：改镜头、查问题、重试、导出都可以是一句话；点卡片编辑字段保留，作为兜底；
- 活动流不是日志窗口：低频、可折叠、终态收敛为一行；
- 一切都有会话身份：项目 × 集 = 一个会话，历史栏即项目列表；
- 页面刷新/换设备回到同一会话，状态从服务端恢复。

## 5. 决策变动清单

**推翻（形态层）**：
- ~~聊天是工作区右侧辅助助手，不是唯一入口~~ → 对话是唯一入口和主界面；
- ~~结果首页是制作总览~~ → 无总览页，结果是对话内工件；
- ~~左侧多页签导航（总览/资产/场次/分镜/问题/版本/导出）~~ → 取消；导航即会话历史栏；
- Q1B（进度是总览页的状态）→ 被吸收：进度就是活动流，无总览页可依附。

**保留（产品原则层，与形态无关）**：
自动连续生成；不做审批；影响范围自动重生成（G2A）；措辞/事实修订边界（G1A）；问题不中断、可忽略、导出记录；锁定 9 文件一键导出（Q2A/G4A）；Mock 全链路 ≤2 分钟（G3A）；分镜卡片非表格；个人操作者、无登录；服务器部署 + Worker + PostgreSQL。
