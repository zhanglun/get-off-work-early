## 2. 分阶段优先级

### P0：第一条纵向业务闭环

目标：一集剧本转成可审查、可修改、可导出的生产包。

- 项目和剧集基础对象
- 约定式 Markdown 剧本导入
- 基础场次格式解析
- 接近行业剧本格式解析
- 剧本结构化解析
- 角色、场景、道具、事件提取
- Story Bible 生成
- 场次拆分
- 分镜生成
- 画面提示词和视频提示词生成
- 一致性审查
- 普通问题自动修订
- 关键变更确认
- Markdown/JSON 导出
- API 异步执行
- Mastra Studio 单次调试

### P1：可用性与质量闭环

- 资产工作区
- 对话式局部修改
- 版本差异
- 局部重跑
- 来源溯源
- 失败步骤重试
- Review Log
- 用户反馈
- Token、延迟和模型记录
- 评估 Fixture

### P2：团队协作和制作管理

- 多用户和角色权限
- 批注和评论
- 任务分配
- 资产锁定
- 多人版本合并
- 场景复用
- 拍摄计划和制作统计

### P3：下游生成和发布

- 图像生成
- 视频生成
- 配音和字幕
- 素材管理
- 剪辑工程导出
- 发布平台适配

### P4：平台化

- 多租户
- 模型路由
- Prompt 模板中心
- MCP
- 插件体系
- 计费和配额

## 3. 第一阶段交互优先级

聊天是主要入口，第一阶段优先保证创作问答体验，同时支持生产指令。

### 生产指令

```text
分析剧本
生成故事资产
生成场次和分镜
重新生成指定镜头
解释审查问题
导出当前确认版本
```

### 创作问答

```text
询问人物动机
讨论剧情冲突和悬念
询问角色、场景、道具和时间线
获取对白、情绪和节奏建议
```

创作问答默认只提供建议；要求修改资产时，必须转化为变更提议，并根据影响范围进入确认流程。

## 4. P0 的明确出界

第一阶段不做：

- 自动生成完整原创长剧本
- 真正的视频生成
- 配音、字幕和剪辑
- 多租户和复杂权限
- 多集跨集连续性
- 团队实时协同
- 图数据库
- MCP 插件市场
- 全自动发布

这些能力保留在路线图中，但不进入第一条验收闭环。

## 5. 能力和用户任务的关系

| 用户任务 | 依赖能力 | P0 是否完成 |
|---|---|---:|
| 导入一集剧本 | 项目、剧集、剧本版本 | 是 |
| 知道剧本讲了什么 | 摘要、剧情事件、场次 | 是 |
| 知道有哪些角色和场景 | Story Bible | 是 |
| 生成可执行分镜 | 场次、分镜、镜头语言 | 是 |
| 生成图像/视频提示词 | Prompt 生产 | 是 |
| 发现角色/场景穿帮 | 连续性审查 | 是 |
| 修改并保留历史 | 版本、diff、来源 | 基础版 |
| 与旧系统比较 | Legacy Comparison | 否，P1 |
| 生成实际视频 | 下游模型集成 | 否，P3 |
