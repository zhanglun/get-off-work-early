# 信息架构与页面结构

> 状态：需求方向已确认，页面方案待评审
>
> 目标：让用户以“项目、剧集、资产、问题、导出”的方式理解系统，而不是以 Agent、Workflow、数据库的方式理解系统。

## 1. 产品导航

```text
短剧分镜制作助手
├── 首页 / 新建制作
├── 最近项目
├── 当前项目
│   └── 当前剧集
│       ├── 制作总览
│       ├── 原始剧本
│       ├── 故事资产
│       │   ├── 角色
│       │   ├── 场景
│       │   ├── 道具
│       │   ├── 人物关系
│       │   └── 时间线
│       ├── 场次
│       ├── 分镜
│       ├── 问题
│       ├── 版本
│       └── 导出
└── 右侧 AI 助手
```

第一版不提供复杂的项目管理和用户权限导航。

## 2. 页面清单

| 页面 | 主要目的 | 主要用户动作 |
|---|---|---|
| 首页 | 开始新的制作任务 | 粘贴/上传剧本 |
| 生成进度 | 了解自动生成状态 | 查看进度、查看已完成内容、重试 |
| 制作总览 | 了解整集结果 | 进入资产、问题、导出 |
| 原始剧本 | 查看输入依据 | 查看原文、版本和来源 |
| 故事资产 | 查看和编辑结构化内容 | 编辑角色、场景、道具、时间线 |
| 场次 | 查看场次规划 | 查看场次目标、冲突、节拍 |
| 分镜 | 查看分镜卡片 | 编辑镜头、Prompt、重试、查看版本 |
| 问题 | 集中处理连续性和生成问题 | 定位、编辑、重试、忽略 |
| 版本 | 查看修改历史 | 查看 before/after、影响范围 |
| 导出 | 生成生产包 | 选择格式、下载 |
| AI 助手 | 辅助问答和操作 | 提问、修改、重试、解释 |

┌──────────────────────────────────────────────┐

│ 把一集剧本变成故事资产、分镜和生产 Prompt        │
├──────────────────────────────────────────────┤

│ 第几集   [ 1                            ]       │
│                                              │
│ [上传 .md / .txt]                             │
│                                              │
│ 或粘贴剧本                                     │
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│             [开始生成]                        │

- 支持的文件类型；
- 自动生成包含哪些内容；
- 任务可以在后台继续；
- 发现问题不会中断整体流程。

## 8. 问题页面

问题卡必须显示：

- 问题等级；
- 问题说明；
- 来源；
- 影响资产；
- 当前处理状态；
- 建议动作；
- 查看、编辑、重试、忽略操作。

```text
⚠ 角色外观不一致
影响：第1场、第3场，共12个镜头
原因：第1场描述为米色风衣，第3场未延续服装状态
[定位资产] [自动修订] [忽略]
```

## 9. 右侧 AI 助手

聊天上下文必须绑定当前项目、剧集和选中的资产。

支持：

- 问当前资产的问题；
- 解释问题；
- 提出修改意图；
- 触发局部重跑；
- 查询版本；
- 发起导出。

不支持：

- 只在聊天文本里保存业务事实；
- 绕过影响分析直接修改全局资产；
- 以聊天结果替代卡片中的结构化版本。

## 10. 响应式要求

第一版优先桌面端，因为分镜卡片、Prompt 和问题需要较宽空间。

移动端最低要求：

- 可以查看任务状态；
- 可以查看资产和问题；
- 可以进行简单聊天；
- 复杂编辑可以提示用户使用桌面端。

## 11. 术语规范

面向用户使用：

- 故事资产；
- 角色卡；
- 场景卡；
- 场次；
- 分镜；
- 问题；
- 重试；
- 版本；
- 生产包。

面向开发文档使用：

- StoryBible；
- Scene；
- Shot；
- PromptVersion；
- Review；
- DomainTask。

用户界面不要求用户理解后面这些内部术语。
