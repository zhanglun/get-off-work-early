## 2. 已关闭的结构决策

### Q1B：生成进度是制作总览页的"进行中"状态（不设独立进度页）

- 进入项目始终落在制作总览页：生成中时顶部显示阶段进度条，已完成卡片实时出现；
- 生成完成后同一页面转为完成状态，不发生跳转；
- 理由：页面更少、"边生成边看"天然成立、避免完成时刻的跳转断裂。
- 落盘：IA §2（页面清单删"生成进度"行）、§4 重写为"生成中状态"、§5 注明同一页面两种状态；user-flows §3 重写。

### Q2A：一键导出完整生产包（不提供格式选择/逐文件下载）

- 导出页 = "导出完整生产包"主按钮 + manifest 内容预览（当前版本/失败项/被忽略问题）；
- 理由：第一版范围封闭，与 G4A（锁定 9 文件）配套。
- 落盘：user-flows §10 删除"选择 Markdown / JSON / 完整生产包"。

## 3. 采用的默认（无需批复，可随时推翻）

- **最近项目落地规则**：点击进行中的项目 → 总览页（生成中状态）；已完成的项目 → 总览页（完成状态）；
