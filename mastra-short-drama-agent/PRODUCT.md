# PRODUCT.md — 短剧分镜制作助手

> 来源：2026-08-30 与用户的 18 轮结构化问答（详见 docs/product-design.md）。
> 本文件是 impeccable 设计流程的产品事实基线。

## 产品一句话

把一集已写完的剧本，通过一个项目主对话自动制作成可编辑、可重生成的分镜生产包（角色/场次/分镜/Prompt），并整项目导出 ZIP。

## 形态与受众

- 可公开演示的 **Demo**（真实可用，非商业系统）。
- 访问：登录页展示固定 Demo 账号（demo / demo123），登录保持 7 天。
- 受众：短剧前期制作人员——编剧助理、导演/分镜师、项目负责人；演示场景是向同行/内部展示"剧本→分镜"的完整闭环。
- 用户懂制作术语（场次、镜号、景别、运镜），不懂 Agent/Workflow/Schema。

## 核心机制（产品自己的东西）

1. 一个项目 = 一个主对话 + 项目级角色世界设定 + 多集；
2. 对话导入剧本 → 依次补问项目名/集数/镜头数 → 一键自动连续生成；
3. 项目级资产 + 当前集覆盖；跨集修改先展示影响范围再确认重生成；
4. 局部失败隔离可重试；取消保留已完成；
5. 真实模型（OpenAI 兼容）优先，失败显式报错并支持重试；
6. 整项目导出 ZIP（project-assets.md + 每集 5 文件）。
